# Toddler Coloring Book

Отдельный сайт под тему первых раскрасок для малышей. Домен: toddlercoloringbook.com

## Что уже работает

- Главная страница на английском и испанском
- Подборщик первой раскраски: четыре вопроса, ответ с бесплатными листами
- Четыре этапа первого рисования, с опорой на опубликованные нормы развития
- 30 бесплатных листов для печати в двух языках и двух форматах бумаги
- Разметка для поисковиков, карта сайта, файл для нейросетей, переброс по языку
- Страница для несуществующих адресов

## Разделы

Тридцать две страницы, по шестнадцать на каждом языке.

    /en, /es                          главная с подборщиком
    /en/by-age                        четыре этапа списком
    /en/by-age/<этап>                 отдельная страница на каждый этап (4)
    /en/guides                        руководства списком
    /en/guides/<статья>               отдельная статья (5)
    /en/free-coloring-pages           30 листов по трем уровням
    /en/coloring-book                 книга
    /en/about                         кто мы
    /en/terms-and-privacy             права на рисунки и приватность (в подвале)

Испанские адреса свои: /es/por-edad/apuntando-a-la-forma,
/es/guias/el-rotulador-traspasa-las-hojas-del-libro и так далее.
Языковые пары связаны в обе стороны.

## Статьи

    что age can a toddler start coloring      с какого возраста
    crayons markers or colored pencils        чем рисовать
    coloring without the mess                 без грязи
    marker bleeds through pages               фломастер насквозь
    how long will a toddler sit and color     сколько выдерживает

Темы взяты из подсказок поиска Amazon, не придуманы.

## Как запустить

    npm install
    npm run dev

Открыть http://localhost:3000

## Как выложить

Vercel, тот же порядок, что и с остальными сайтами. Домен подключается
через CNAME или ALIAS, не через A-записи.

## Что менять при обновлении текстов

`src/lib/site.ts`, строка SITE_UPDATED. Эта дата уходит в разметку страниц
и говорит поисковику и нейросетям, что материал живой.

## Где что лежит

    src/data/stages.ts       четыре этапа, ядро всего сайта
    src/data/sheets.ts       бесплатные листы по уровням сложности
    src/data/book.ts         книга, два издания
    src/data/dictionaries.ts все надписи на двух языках
    src/components/Picker.tsx подборщик
    src/lib/schema.ts        разметка для поисковиков
    public/llms.txt          справка для нейросетей
    public/printables/       листы для печати
