Toddler Coloring Book. Немецкая страница про английскую книгу.
Адрес: /de/malbuch-erste-woerter-englisch

Полный набор изменений этой страницы: тексты, картинки, цена, порядок
кнопок, заголовки, мятные кружки, выключка текста по обе стороны,
верхняя строка с переносом после слова Kinder, строка про вторую книгу
внизу с разведенными текстом и кнопкой.

Три раскрашенных листа (лев, лиса, корова) стоят в один ряд на любом
экране, включая телефон. Прежнее правило сайта, скрывавшее на телефоне
третью картинку из ряда квадратных, теперь этот ряд не затрагивает.
На остальных страницах сайта оно работает как раньше.

Остальные семь европейских страниц не затронуты.
