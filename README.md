# Английский баннер

Кладется поверх предыдущего архива. Два файла:

    public/banner/top-en-wide.jpg   новый английский баннер
    src/components/Chrome.tsx       шапка берет его по новому имени

## Что было не так

Испанский и русский стоят правильно, английский был выше почти вдвое.
Картинки тут ни при чем: все три обрезаны одинаково, разница в высоте
между языками четыре точки.

    английский   2172 x 490
    испанский    2172 x 487
    русский      2364 x 526

Дело в имени файла. Первый английский баннер лежал под именем
`top-en.jpg` и был 2388 x 800, то есть почти вдвое выше. Новый файл
пришел под тем же именем, и старый остался: либо не заменился при
распаковке, либо его продолжает отдавать кеш браузера или сети.

Поэтому имя изменено на `top-en-wide.jpg`. Со старым файлом оно не
спорит, и подставить прежнюю картинку уже нечему.

## Можно убрать

Файл `public/banner/top-en.jpg` больше не используется, его можно
удалить из репозитория.
