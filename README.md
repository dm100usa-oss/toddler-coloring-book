# Уменьшенный баннер

Один файл: `src/app/globals.css`.

Баннер в шапке больше не растягивается на всю ширину окна. Ширина
ограничена 980 точками, высота выходит около 330 вместо 470, и обложка
книги попадает в первый экран.

Раньше баннер занимал весь первый экран целиком, и книгу приходилось
искать прокруткой. Человек приходит на этот сайт за книгой, она обязана
быть видна сразу.
