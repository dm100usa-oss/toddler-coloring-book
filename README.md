Toddler Coloring Book. Европейские страницы. Полный набор картинок.

В этом архиве лежат ВСЕ картинки шести страниц, которые делались
после немецких: французских, голландских и польских. Двадцать четыре
файла. Немецкие двенадцать уже стоят на сайте с прошлых раз и здесь
не повторяются.

Заливать можно поверх, файлы просто заменятся или добавятся.

src/data/euro.ts    тексты и настройки всех восьми страниц
public/art/         24 картинки: fr-en, fr-es, nl-en, nl-es, pl-en, pl-es

Все восемь страниц после этого архива полные: свои тексты, свое
оформление, свои шесть картинок на каждую.
