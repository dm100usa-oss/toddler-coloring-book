# Баннеры на трех языках

Накладывается поверх предыдущего архива.

    public/banner/top-en.jpg    английский
    public/banner/top-es.jpg    испанский
    public/banner/top-ru.jpg    русский
    src/components/Chrome.tsx   шапка показывает баннер своего языка
    src/app/globals.css         ширина баннера

Старый файл `public/banner/top-en.jpg` заменяется новым, обрезанным.

## Что сделано с картинками

Обрезаны сверху и снизу по самому рисунку, с небольшим полем, чтобы лев
и пончик не упирались в край. Пустые поля в исходных файлах занимали
примерно треть высоты.

    было   2172 x 724      на экране около 470 точек высоты
    стало  2172 x 490      на экране около 245 точек высоты

Запасной шапки текстом больше нет: баннер теперь есть на каждом языке.

## Одна правка, которая нужна в самой картинке

В русском баннере в нижней строке написано «Морские обитателя».
Правильно «Морские обитатели». Исправить нужно в исходном файле
и прислать картинку заново, я поставлю ее на место.
