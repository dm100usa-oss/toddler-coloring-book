# Toddler Coloring Book

Сайт о первых раскрасках для детей от года до трех лет:
toddlercoloringbook.com

Сайт помогает родителям, воспитателям и специалистам выбрать раскраску,
которая подходит ребенку по его нынешним умениям, а не по цифре на
обложке. На сайте есть подборщик по четырем признакам, страницы по
возрастам, четыре этапа развития рисования, статьи и бесплатные
страницы для печати.

Сайт издает Magic of Discoveries LLC, Майами, Флорида. Издательство
выпускает книгу First Coloring Book for Toddlers Ages 1-3: 111 крупных
рисунков с толстым контуром, по одному на страницу, печать с одной
стороны. Книга выходит на английском и испанском языках в бумаге и
на русском файлом для печати.

Сайт работает на трех языках: английском, испанском и русском.
Сделан на Next.js, размещен на Vercel.
