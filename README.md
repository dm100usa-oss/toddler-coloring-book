# toddlercoloringbook.com

Сайт о первых раскрасках для детей от 1 до 3 лет. Отвечает на вопросы, с
которыми взрослый приходит к первой раскраске: когда давать ребенку мелки и
карандаши, какая раскраска подходит в этом возрасте, почему у одного ребенка
получается, а у другого нет. Одна книга показана на главной как образец
такой раскраски.

Три языка: английский, испанский, русский. Тексты на каждом языке написаны
отдельно, а не переведены друг с друга.

## Для кого

- родители детей 1-3 лет,
- воспитатели детских садов и ведущие детских групп,
- логопеды и специалисты раннего вмешательства,
- программы и организации, закупающие раскраски для семей.

## Разделы

- главная: книга как пример, подборщик раскраски, бесплатные листы,
- «По возрасту»: четыре этапа первого рисования,
- «Статьи»: разборы частых вопросов,
- «Для программ» и страницы для специалистов,
- бесплатные листы для печати.

## Как устроено

Next.js, разметка страниц в `src/app`, весь текст в `src/data`, картинки и
файлы для печати в `public`. Сайт собирается заранее в готовые страницы и
работает на Vercel.

Запуск на своем компьютере:

    npm install
    npm run dev

Проверка перед сдачей:

    npx tsc --noEmit
    npm run build

## Правила проекта

- буква «ё» и длинное тире в текстах не используются,
- три языка всегда обновляются вместе,
- никаких обещаний пользы для здоровья,
- возраст дается как разброс, а не как срок, с указанием источников,
- каждый абзац закончен сам по себе, без отсылок «как сказано выше»: так
  нейросеть может процитировать любой кусок отдельно.
